Frequently Asked Questions

No. CV-Fix has no database backend. Your Master LaTeX template, optimization history, and Gemini or Anthropic API keys stay inside your local IndexedDB sandbox (via idb-keyval), and requests only go directly to the AI endpoint you choose.

The Mutation Engine runs at low temperature (0.1) with strict system rules forbidding changes to \documentclass, margins, packages, \resumeSubheading, or \resumeItemListStart. Only the text inside bullets, summary, and skills updates — and you can reset or edit any line directly in Monaco.

CV-Fix includes dedicated extractors for Greenhouse, Lever, Ashby, and public LinkedIn job pages alongside generic HTML parsing. If a site blocks proxy scraping, you can paste the unstructured job description directly into the text box.

You can bring your own Google Gemini 2.0 Flash or Anthropic Claude 3.5 Sonnet API key, or use Keyless Local Gemini CLI mode inside the Tauri macOS desktop app (or local Vite dev server) if gemini is installed on your system path.

CV-Fix parses your LaTeX resume into a live A4 HTML facsimile matching standard LaTeX serif layout. Click Download PDF to save cleanly via system print (@media print), or download the mutated .tex file for Overleaf or pdflatex.
